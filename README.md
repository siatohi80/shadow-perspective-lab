# Shadow Perspective Lab

An interactive page for teaching cast shadows in one- and two-point perspective.

- Add architectural forms (cube, tower, L-building, gable house, pyramid roof, column, arch, stairs, wall with canopy) or import your own 3D models (GLB, glTF, OBJ, STL).
- Switch between a sun (parallel rays) and a point light, and drag the light in front of or behind the forms.
- Change the view: one-point, two-point (level camera, verticals stay vertical) or free orbit.
- Construction overlay: horizon line, vanishing points, light rays (orange), shadow lines (green) and shadow points (red).

Open the live page: https://siatohi80.github.io/shadow-perspective-lab/

Built with [three.js](https://threejs.org) r128 (MIT license, included in this repo).
